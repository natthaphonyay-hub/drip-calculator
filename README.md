# Drip Calculator

เว็บคำนวณจำนวน amp หรือ vial ของยาฉีดที่ผสมหยดต่อเนื่อง ต่อ 1 order พร้อม Pharmacist note ให้คัดลอกไปวางในระบบ และตารางเปลี่ยนถุง ทำเป็นชุดเดียวกับ ATB Calculator

- เปิดใช้: https://natthaphonyay-hub.github.io/drip-calculator/
- ดูตัวอย่าง: https://natthaphonyay-hub.github.io/drip-calculator/?example=1

ตัวอย่าง: Norepinephrine 4 mg/amp ผสม 8 mg ใน 500 ml หยด 30 ml/hr นาน 24 ชม.
ใช้ 720 ml หมด 2 ถุง ถุงละ 2 amp จึงต้องเตรียม 4 amp (ยาที่ผู้ป่วยได้รับจริง 11.52 mg และครบ 24 ชม. ถุงที่ 2 ยังเหลือ 280 ml)

## วิธีคิด

1. ยาต่อถุง = ปริมาณที่ผสม (ใส่เป็นหน่วยยาหรือเป็นจำนวนหลอดก็ได้)
2. หลอดต่อถุง = ยาต่อถุง หาร ยาต่อ 1 หลอด แล้วปัดขึ้น เพราะหลอดที่เปิดแล้วใช้ต่อไม่ได้
   ถ้าเป็น multi-dose vial ที่เก็บใช้ต่อได้ ติ๊กตัวเลือกเพิ่มเติม จะปัดขึ้นจากยอดรวมแทน
3. 1 ถุงหยดได้ = ปริมาตรถุง หาร อัตรา ml/hr (ถ้าใส่เวลาเปลี่ยนถุงที่สั้นกว่า ใช้เวลานั้นแทน)
4. จำนวนถุง = ระยะเวลา หาร เวลาที่ 1 ถุงหยดได้ แล้วปัดขึ้น (หักเวลาที่ถุงเดิมยังหยดได้ก่อน ถ้ามี)
5. จำนวนหลอดที่ต้องเตรียม = จำนวนถุง คูณ หลอดต่อถุง

สั่งเป็นขนาดยาก็ได้ (เช่น mcg/kg/min, mg/hr, unit/hr, mEq/hr) แอปจะแปลงเป็น ml/hr จากความเข้มข้นให้

## รายการยา (Google Sheet)

แอปอ่านรายการยาและขนาดบรรจุจาก Google Sheet แท็บ `ยา` ให้เภสัชเพิ่มหรือแก้ยาเองได้โดยไม่ต้องแก้โค้ด
ถ้ายังไม่ได้ตั้งค่าหรือโหลดชีตไม่ได้ แอปจะใช้รายการที่จำไว้ในเครื่อง หรือรายการตั้งต้น 3 ตัว

ตั้งค่าครั้งแรก (ทำครั้งเดียว)

1. อัปโหลด `sheet-template/drug-list-template.xlsx` ขึ้น Google Drive แล้วเปิดด้วย Google ชีต
   (ไฟล์ > บันทึกเป็น Google ชีต) ให้ได้แท็บ `ยา` และ `วิธีใช้`
2. กด แชร์ > การเข้าถึงทั่วไป > ทุกคนที่มีลิงก์ > ผู้ดู
3. เพิ่มอีเมลคนที่ดูแลรายการยาเป็น ผู้แก้ไข
4. คัดลอก ID ของชีต (ข้อความยาวในลิงก์ระหว่าง `/d/` กับ `/edit`) ไปใส่ใน `index.html` บรรทัด `const SHEET_ID = '';`

หัวคอลัมน์แท็บ `ยา` (ห้ามเปลี่ยนชื่อ): `ชื่อยา` `ยาต่อหลอด` `หน่วย` `ml ต่อหลอด` `ชนิดบรรจุ` `ผสมยา` `ผสมใน ml` `สารละลาย` `หมายเหตุ`
แถวที่ไม่มีตัวเลขยาต่อหลอดหรือไม่มีหน่วย แอปจะข้ามและบอกจำนวนแถวที่ข้าม

ห้ามใส่ข้อมูลผู้ป่วยในชีต เพราะชีตเปิดให้ทุกคนที่มีลิงก์ดูได้

## วางใน Google Sites

แทรก > ฝัง > ตาม URL > วางลิงก์ `https://natthaphonyay-hub.github.io/drip-calculator/` > เลือก ทั้งหน้า แล้วปรับขนาดกรอบ
แก้โค้ดบน GitHub ครั้งเดียว หน้าใน Google Sites จะเปลี่ยนตามเอง

## ทดสอบ

```
node tests/test-calc.mjs
```

ชุดทดสอบอ่านส่วนคำนวณใน `index.html` (ระหว่าง `CALC-START` กับ `CALC-END`) แล้วตรวจตัวอย่างจริง เช่น Norepinephrine, KCl, Heparin รวมทั้งหน้าตา Pharmacist note ทุกบรรทัด
