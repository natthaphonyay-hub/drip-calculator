# Drip Calculator

เว็บคำนวณจำนวน amp หรือ vial ของยาฉีดที่ผสมหยดต่อเนื่อง ต่อ 1 order พร้อม Pharmacist note ให้คัดลอกไปวางในระบบ และตารางเปลี่ยนถุง ทำเป็นชุดเดียวกับ ATB Calculator

- เปิดใช้: https://natthaphonyay-hub.github.io/drip-calculator/
- ดูตัวอย่าง: https://natthaphonyay-hub.github.io/drip-calculator/?example=1

ตัวอย่าง: Norepinephrine 4 mg/amp ผสม 8 mg ใน 500 ml หยด 30 ml/hr นาน 24 ชม. ใช้ 720 ml หมด 2 ถุง ถุงละ 2 amp จึงต้องเตรียม 4 amp

## ใช้งาน

1. ค้นหายา พิมพ์บางส่วนของชื่อ (เช่น nor, kcl, amio) แล้วเลือก ถ้าไม่มีในรายการ เลือก "อื่นๆ" แล้วกรอกเอง
2. เลือกสารน้ำ แอปแสดงเฉพาะสารน้ำที่ยานั้นผสมได้ตามแหล่งอ้างอิง
3. เลือกสูตรผสมมาตรฐาน หรือกรอกเอง
4. ใส่อัตราเป็น ml/hr หรือเป็นขนาดยา (เช่น mcg/kg/min, unit/hr, mU/min) แอปแปลงเป็น ml/hr ให้
5. ส่วนพิเศษ: loading dose (ผสมแยก, IV bolus หรือจากถุงเดียวกัน) และการเปลี่ยนอัตราระหว่างให้ ยาที่มีสูตรตามแหล่งอ้างอิง (เช่น Amiodarone) กดปุ่มเดียวใส่ให้ครบ
6. ตัวเลือกเพิ่มเติม: ถุงที่แขวนอยู่ยังเหลือ (คิดรอบถัดไป), เวลาเปลี่ยนถุงตามความคงตัว, นับปริมาตรยาที่เติม, multi-dose vial

## วิธีคิด

1. ยาต่อถุง = ปริมาณที่ผสม (ใส่เป็นหน่วยยาหรือเป็นจำนวนหลอดก็ได้)
2. หลอดต่อถุง = ยาต่อถุง หาร ยาต่อ 1 หลอด แล้วปัดขึ้น เพราะหลอดที่เปิดแล้วใช้ต่อไม่ได้
   ถ้าเป็น multi-dose vial ที่เก็บใช้ต่อได้ ติ๊กตัวเลือก จะปัดขึ้นจากยอดรวมแทน
3. แอปเดินตามเวลาของ order: loading ก่อน แล้วจึงหยดต่อเนื่อง เปลี่ยนอัตราตามที่สั่ง
   ถุงหนึ่งจบเมื่อหมด เมื่อครบเวลาเปลี่ยนถุง หรือเมื่อครบเวลา order แล้วจึงเปิดถุงใหม่
4. จำนวนหลอดที่ต้องเตรียม = จำนวนถุง คูณ หลอดต่อถุง บวกหลอดของ loading ที่ผสมแยก

## ข้อมูลยา

ข้อมูลยา 22 รายการอยู่ใน `index.html` ระหว่าง `DATA-START` กับ `DATA-END` ทุกค่าระบุแหล่งที่มา (บัญชียา รพ., เอกสาร HAD ของ รพ. ไทย, ฉลากยา)
ค่าที่ยังไม่มีเอกสารยืนยันจะแสดงป้าย "ยังไม่ยืนยัน" ในแอป ก่อนใช้จริงให้เทียบกับแนวทาง HAD ของโรงพยาบาล
แก้หรือเพิ่มยา: แก้ในบล็อก DATA แล้วรันชุดทดสอบด้านล่าง

## ทดสอบ

```
node tests/test-calc.mjs        # ชุดทดสอบตัวคำนวณและข้อความ note (ล็อกทุกบรรทัด)
python3 tests/fuzz.py 30000     # สุ่มโจทย์เทียบกับตัวคำนวณอีกตัวที่เขียนแยก (tests/reference.py, เลขเศษส่วน)
python3 tests/e2e_check.py      # กดใช้หน้าเว็บจริงใน Chrome ทุกยา ทุกสูตร ทุกสารน้ำ แล้วเทียบตัวเลขบนจอ
node tests/make-hand-check.mjs  # สร้าง docs/ตารางตรวจมือ-การคำนวณ.md ไว้ตรวจด้วยเครื่องคิดเลข
```

ผลตรวจ 5 พ.ย. 2569: ชุดทดสอบผ่าน 37 ข้อ, สุ่มเทียบรวมกว่า 94,000 โจทย์ไม่ตรง 0 ข้อ, หน้าเว็บจริง 196 กรณีไม่ตรง 0 ข้อ
